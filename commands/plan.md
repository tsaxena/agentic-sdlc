# Stage 3 - Plan

Read `DESIGN.md` and `AGENTS.md`. Do not reread `INTENT.md` or `CHALLENGE.md`. Treat `DESIGN.md` as the authoritative handoff.

## Process

Apply the `implementation-planning` skill, including its self-check before presenting.

Produce the smallest ordered plan that gets a real input to a real output through the real architecture. Split work into P0 (required), P1 (if time allows), and out of scope. Size P0 against the build budget in `AGENTS.md`, not against completeness.

## Output

`IMPLEMENTATION_PLAN.md`, opening with the `## Contract` section copied verbatim from `DESIGN.md`.

## Boundaries

Do not write code, add features absent from `DESIGN.md`, or promote P1 work into P0 without saying why. If planning reveals the design must change, stop and return to Stage 2.

## Budget

5 minutes. A plan that takes longer than that to write is too big to build.

## Human Gate

Present the plan for approval. Stop.
